# Idle Heroes Knowledge Base

A personal knowledge base for Idle Heroes, set up so Claude can read it and give strategy advice for this specific account.

| Folder | Contents |
|---|---|
| [account/](account/) | My profile, goals and hero roster. **Keep this current: it's what makes advice personal.** |
| [heroes/](heroes/) | One file per hero: role, skills, best uses, artifacts and gear |
| [game-modes/](game-modes/) | Notes on each mode (Campaign, Arena, Guild Boss, Void, etc.) |
| [strategies/](strategies/) | Team comps, resource plans and progression guides |
| [reference/](reference/) | Glossary, faction advantage and general mechanics |
| [logs/](logs/) | Dated log of decisions and progress |

## Workflow

1. Fill in `account/profile.md` and `account/roster.md`.
2. Ask Claude questions from this folder (e.g. "What team should I use for Guild Boss?" or "Should I star up X or Y next?").
3. Ask Claude to save new findings here (e.g. "Add this team to strategies" or "Update my roster: I just made a hero E1").
